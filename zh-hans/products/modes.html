Modes macOS版

Modes是适用于macOS的乐理应用，涵盖音阶、和弦、和弦排列和转调路径，采用侧边栏布局，可以放在DAW旁边使用。支持Siri、Shortcuts、Spotlight搜索和通知中心小组件。

  • 音阶与和弦查找器，支持MIDI + 屏幕键盘
  • 65种音阶 · 21种和弦类型 · 8种和弦排列类型
  • 共享音符、共享和弦、借用和弦
  • 互动五度圈 + 三度圈
  • Siri、Shortcuts、Spotlight与通知中心小组件

功能特色

  • 在互动多八度键盘上弹奏音符，或连接MIDI控制器，Modes会实时识别您演奏的和弦：大调、小调、减和弦、增和弦、延伸和弦、挂留和弦等。它按音符覆盖率对每个匹配的音阶进行排名，结果可以按音阶类别（自然音阶、旋律小调、和声小调、五声音阶、Bebop、对称、世界音阶等）筛选。
  • 65种音阶与调式包括七种自然调式、旋律小调、和声小调、双重和声、那不勒斯、Bebop、五声、蓝调、全音阶、减音阶、增音阶，以及Hirajōshi、Kumoi、In Sen、Persian和Enigmatic等世界音阶。每种音阶都标注了音程符号并在键盘上高亮显示。
  • 选择任意根音和音阶，即可看到两个八度上高亮显示的每个调内音符，哪些音符属于该调、根音在哪里一目了然。
  • Modes为所选音阶的每个音级生成自然三和弦或七和弦，附有罗马数字、和弦名称、和声功能标签（主功能、下属功能、属功能及30多个详细标签）以及按和弦排列显示的键盘，并对齐以便比较。
  • 和弦可按三度叠置、sus2、sus4、六度、附加、四度叠置、五度叠置和强力和弦这8种和弦排列构建，从三和弦到十三和弦，每个扩展音自动标注。
  • "共享音符"与"共享和弦"可并排比较任意两个调：哪些音符重叠、哪些独有、哪些和弦两个调共享。这对转调和重新和声编配有帮助。
  • "借用和弦"视图列出您所在调的自然和弦，以及来自平行调式的所有可借用和弦，按来源调式分组。
  • 五度圈是可交互的双环圆（外圈大调，内圈自然小调）。点击扇区可重新设定调性。图上显示属、下属、关系调、同主音调和相近调，并带有转调难度标签和调号详情。
  • 三度圈在减七和弦循环图上显示半音中音关系。每个音级的大调和小调按钮会显示中音、关系调和同主音调的连接，适用于电影配乐和新里曼转调规划。
  • 可连接任何符合标准的MIDI键盘或控制器。演奏的音符会与屏幕点击合并后进行识别。
  • 让Siri或运行Shortcut来显示音阶的音符、列出某个调的和弦、识别音阶或和弦、拼出和弦、查找两个音符之间的音程、移调音符，或打开五度圈和借用和弦。音阶和和弦也已编入Spotlight索引。
  • 每日音阶和每日和弦小组件可以添加到通知中心。

五度圈

五度圈导航，包含每个调的关系调数据。

C → G → D → A → E → B → F♯/G♭ → D♭ → A♭ → E♭ → B♭ → F → C

每个调都会显示其关系小调/大调、同主音大调/小调、属调、下属调、上主音和中音关系，并附有转调难度标记和调号详情。

三度圈

按大三度与小三度交替（4-3-4-3 个半音）将音高排列成24音的循环序列（12个大三度位置 + 12个小三度位置），有助于理解三和弦与七和弦如何叠置。

  • 音符按1-3-5-7-2-4-6的顺序排列（例如C-E-G-B-D-F-A），也就是和弦音叠置的顺序。
  • DFACEGB助记口诀涵盖降号调、自然调和升号调三个调族中的自然音阶三度。
  • 它由三个减七和弦循环组成，每个循环有四个位置。
  • 可用于Coltrane changes和半音中音关系。

借用和弦（调式互换）

对于任何调，应用都会列出自然和弦以及从平行调式借用的和弦，每个都标注变化罗马数字和常见用法说明。
